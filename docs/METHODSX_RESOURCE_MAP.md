## Provisional resource-availability statement

The R source code, locked software environment, deterministic synthetic fixture,
tests, and documentation are publicly available from the versioned GitHub
repository `https://github.com/guasoni/OPSPL-Reproducibility`. OptionMetrics
observations and row-level derivatives are not distributed. Licensed users can
create the required exports using the supplied SQL-equivalent extraction
criteria, schemas, filenames, and date coverage. Public auxiliary inputs are
either distributed with provenance or retrieved and fingerprinted by the R
pipeline.

## Method-validation narrative

The article can distinguish four forms of evidence:

1. hand-verifiable tests of pricing, return, optimization, solvency, and margin
   formulas;
2. a deterministic synthetic integration example that exercises all public code
   paths without commercial observations;
3. paper-vintage comparisons for the covered empirical results; and
4. a separate-machine licensed-data reproduction record.

The synthetic fixture validates software behavior, not the paper's empirical
estimates. The licensed-data test and paper-value comparisons provide the
empirical validation.

## Limitations to state in the article

- Exact historical reproduction requires access to OptionMetrics and may require
  the archived vendor vintage; a current export is a current-vintage re-estimation.
- Yahoo and FRED observations can be revised or temporarily unavailable. Every
  retrieval is therefore dated and fingerprinted, and the DJIA archive is pinned.
- The initial release covers the exhibits declared in `docs/COVERAGE.md`, not
  every ancillary artifact in the JEF article.
- A full licensed-data run takes several hours and requires storage for a raw
  option export of approximately 9.2 GB plus generated intermediates.
- The workflow is a reproducible research implementation, not trading software
  or investment advice.
